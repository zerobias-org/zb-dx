Proof task
A requirement is only different from a plain task because you map how you discharge it to a boundary control. That mapping auto-populates the proof task; with no mapping it's just a blank ad-hoc task. Status is derived from the anchored controls' evidence — all satisfied → Satisfied, some → Partial, none → Gap.
