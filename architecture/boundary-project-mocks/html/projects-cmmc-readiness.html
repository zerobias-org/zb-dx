How this is computed
Readiness is not owned by the boundary — it is computed here in the project from the anchored requirement → internal-control mappings: each CMMC practice is mapped to a control the Platform satisfies. Crosswalks only suggested those mappings (advisory) — they don't drive the number. Partial coverage rolls up as a percentage (a mostly-met practice counts partial); only genuine gaps become tasks.
